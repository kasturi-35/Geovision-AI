# GEO VISION AI — SIH 2026 Prototype

## Run
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   npm install
5. Run:
   npm run dev
6. Open the localhost URL shown by Vite.

## Prototype scope
This is a front-end demonstration using clearly labelled demo data. It demonstrates:
- AI + GIS dashboard
- Interactive OpenLayers map
- Parcel selection
- Confidence scoring
- Layer controls
- AI extraction workflow
- Topology validation
- Human-in-the-loop review
- Reports

The prototype does not claim a live connection to government cadastral databases and does not make legal ownership decisions.
